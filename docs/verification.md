# 검증 결과

검증일: 2026-09-15 (KST). GitHub Pages와 실제 Firebase 프로젝트 연결을 완료했습니다.

## 자동 검증

- 게임 / 권한 / 입력 검증 18개 통과.
- Firestore Emulator 보안 규칙 테스트 6개 통과.
- Auth + Firestore + Functions Emulator 통합 테스트 7개 통과.
- 운영용·미리보기 프런트엔드 빌드와 Functions TypeScript 빌드 통과.
- 프런트엔드와 Functions의 운영용 의존성 `npm audit --omit=dev`: 알려진 취약점 0개. 개발 도구 의존성에는 moderate 등급 경고가 남아 있으며 실제 앱 번들에 포함되지 않습니다.

Firebase 없이 실행하는 `npm test`는 에뮬레이터 테스트 13개를 건너뜁니다. 해당 13개는 각각 `npm run test:rules`, `npm run test:backend`로 별도 실행해 통과했습니다.

### 검증한 주요 경계

1. 개인 입장 코드를 서버가 검증하고 해당 참가자의 Custom Token으로 인증.
2. 정상 입장 32회가 동일한 네트워크의 로그인 실패 제한을 소모하지 않음.
3. 익명 사용자와 일반 참가자의 관리자 동작 차단.
4. 새 참가자는 항상 member 역할로 생성, superadmin 입력 우회 차단.
5. 슈퍼 어드민만 추가 관리자 지정 가능, dave.h 강등 차단.
6. 초대 링크 재발급 시 이전 코드와 세션 버전 모두 차단.
7. 동시에 같은 보물을 찾을 때 한 사람만 성공하고 점수 중복 지급 없음.
8. 보물 반경 밖 / 오래된 좌표 / 불확실한 위치 / 일시 정지 상태의 발견 차단.
9. 꽝을 찾은 사용자에게만 서버 기준 5분 제한 적용, 제한 종료 후 재개.
10. 참가자의 꽝 종류·초대 문서 열람과 직접 점수·권한 쓰기 차단.
11. 이미 발견한 보물의 수정 및 발견 후 팀 변경 차단. 삭제는 아래 ‘관리자 삭제·초기화’ 변경부터 가능하며 지급 점수와 발견 기록도 함께 취소.
12. 자신의 입장 링크를 재발급하다 새 링크를 보기 전에 세션을 잃지 않도록 화면에서 자신의 재발급 차단.

## 핀치 줌 수정 검증 (2026-09-15)

- Kakao SDK의 `scrollwheel: false`가 휠뿐 아니라 모바일 멀티터치 확대·축소도 비활성화하는 원인을 확인하고 `true`로 수정했습니다.
- 독립된 Chrome에서 실제 SDK와 운영 지도 컴포넌트를 로드한 뒤 브라우저의 두 손가락 터치 입력으로 비교했습니다.
- 수정 전: 핀치 축소·확대 모두 지도 레벨 3 유지. 데스크톱 휠도 레벨 3 유지.
- 수정 후: 핀치 축소 3 → 5, 핀치 확대 5 → 3. 트랙패드 방식 Ctrl+휠 축소는 3 → 4.
- 핀치 중 페이지 배율은 1을 유지했고, 관리자 보물 배치 콜백은 호출되지 않았습니다.
- 세부 결과는 Git에서 제외한 `artifacts/pinch-before.json`, `artifacts/pinch-after.json`에 저장했습니다.

## 힌트 기반 탐색 변경 (2026-09-15)

- 참가자 지도에는 발견 완료 보물과 현재 위치만 표시. 미발견 보물은 좌표 없이 이름·힌트·포인트만 제공.
- 관리자 원본 상태와 참가자 상태를 분리하고 서버 트랜잭션에서 함께 갱신. 일반 참가자는 원본 좌표 문서를 읽을 수 없음.
- 사용자 위치를 받아 8방위 방향, 10m 단위의 대략적인 거리, 접근 단계와 탐험 온도를 반환. 탐색 요청은 조회만 수행하며 이동 경로를 저장하지 않음.
- 큰 지도에서 방향·온기 안내, 핀치 줌 유지, 수동 지도 이동 시 자동 따라가기 해제, 위치 버튼으로 복귀.
- 단위 테스트 29개, Firestore 보안 규칙 8개, Auth/Functions/Firestore 통합 9개 통과 (총 46개).
- 격리된 모바일 브라우저에서 미발견 핀 0개, 힌트 6개, 탐색 온도 15 → 35 → 60 → 100, 핀치 줌 후 GPS 갱신 시 배율 유지 검증.
- 발견 성공 후에만 핀 1개가 표시되고 GPS 감시가 해제됨. 관리자에서 축소하면 전체 보물 6개가 표시됨. 페이지 오류·가로 넘침 없음.
- 브라우저 검증은 별도의 예시 데이터 환경에서 수행했고, 운영 보물·팀·일정·공지 데이터는 보존함.
