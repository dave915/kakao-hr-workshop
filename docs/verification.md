## 자동 검증

- 게임 / 권한 / 입력 검증 18개 통과.
- Firestore Emulator 보안 규칙 테스트 6개 통과.
- Auth + Firestore + Functions Emulator 통합 테스트 7개 통과.
- 운영용·미리보기 프런트엔드 빌드와 Functions TypeScript 빌드 통과.
- 프런트엔드와 Functions의 운영용 의존성 `npm audit --omit=dev`: 알려진 취약점 0개. 개발 도구 의존성에는 moderate 등급 경고가 남아 있으며 실제 앱 번들에 포함되지 않습니다.

Firebase 없이 실행하는 `npm test`는 에뮬레이터 테스트 13개를 건너뜁니다. 해당 13개는 각각 `npm run test:rules`, `npm run test:backend`로 별도 실행해 통과했습니다.

1. 개인 입장 코드를 서버가 검증하고 해당 참가자의 Custom Token으로 인증.
2. 정상 입장 32회가 동일한 네트워크의 로그인 실패 제한을 소모하지 않음.
3. 익명 사용자와 일반 참가자의 관리자 동작 차단.
4. 새 참가자는 항상 member 역할로 생성, superadmin 입력 우회 차단.
5. 슈퍼 어드민만 추가 관리자 지정 가능, dave.h 강등 차단.
6. 초대 링크 재발급 시 이전 코드와 세션 버전 모두 차단.
7. 동시에 같은 보물을 찾을 때 한 사람만 성공하고 점수 중복 지급 없음.
8. 보물 반경 밖 / 오래된 좌표 / 불확실한 위치 / 일시 정지 상태의 발견 차단.
9. 꽝을 찾은 사용자에게만 서버 기준 5분 제한 적용, 제한 종료 후 재개.
10. 참가자의 꽝 종류·초대 문서 열람과 직접 점수·권한 쓰기 차단.
11. 이미 발견한 보물의 수정 및 발견 후 팀 변경 차단. 삭제는 아래 ‘관리자 삭제·초기화’ 변경부터 가능하며 지급 점수와 발견 기록도 함께 취소.
12. 자신의 입장 링크를 재발급하다 새 링크를 보기 전에 세션을 잃지 않도록 화면에서 자신의 재발급 차단.

## 큰 지도 실시간 위치·방향 (2026-09-15)

- 큰 지도를 열면 선택한 힌트가 없어도 GPS 감시를 시작. 보물 탐색 GPS와 중복하지 않고 한 개의 감시로 내 위치를 갱신하며, 보물 방향 안내는 기존 서버 조회 간격 유지.
- 위치 점 위에 휴대폰이 향하는 화살표, 상단에 GPS 상태·오차·바라보는 방위·각도 표시. 기기가 평평할 때와 세워져 있을 때, 세로·가로 화면 방향을 반영. 상대 방향 값만 제공되는 환경에서는 잘못된 북쪽 방향을 표시하지 않음.
- 회전 시 마커 화살표만 갱신하고 지도와 위치 오버레이는 재생성하지 않음. GPS 갱신 중 지도 확대 수준 유지, 수동 이동 후 자동 복귀 방지, 내 위치 버튼으로 따라가기 재개 확인.
- 위치가 오래되면 마지막 위치를 흐리게 표시하고 방향 정보가 만료되면 화살표 숨김. 방향 권한 거부 시 GPS 표시 유지, 방향 다시 켜기 후 복구 확인.
- 실제 카카오맵과 가상 GPS·방향 센서를 사용하는 390px 브라우저에서 검증. 힌트 없는 큰 지도 종료 시 GPS 감시 0개, 방향 리스너 0개 확인. 힌트 탐색 중 위치·방향·보물 안내가 함께 표시되고 감시가 한 개만 실행되는 것을 확인.
- 단위 테스트 50개와 프런트엔드·Functions 빌드 통과. 큰 지도 하단 AR 버튼이 좁은 열에서 세로로 줄바꿈되던 배치도 수정. 실제 휴대폰의 자기장 간섭·GPS 정확도는 기기와 현장에 따라 다름.

## 카메라 필수 획득 (2026-09-15)

- 지도 안의 바로 획득 동작을 카메라 열기로 변경하고 미리보기 획득 우회 버튼 제거. 획득 호출은 카메라 컴포넌트에서만 수행.
- 영상 트랙이 활성 상태이고 사용 가능하며 실제 영상이 재생 중인지 확인. 영상 일시 정지·중단·크기 없음·화면 비표시 상태를 차단하고 버튼 클릭 시에도 현재 상태를 다시 검사.
- 새 액션 `claimCamera` 사용. 인증된 참가자가 실제 발견 반경 안에서 보내는 이전 `claim` 요청도 서버에서 거부하고, 상태가 바뀌지 않는 것을 통합 테스트로 확인.
- 단위 테스트 54개, Firebase 에뮬레이터 통합 테스트 14개 및 프런트엔드·Functions 빌드 통과.
- 390px 브라우저에서 지도 → 카메라 이동 시 점수 0 유지, 카메라 시작 전 획득 버튼 없음, 재생 중 획득 가능, 영상 일시 정지 직후 기존 버튼 클릭도 차단, 재생 복구 후 100점 획득 및 카메라·센서·GPS 정리 확인. 카메라·GPS·방향은 테스트용 시뮬레이션으로 검증.
