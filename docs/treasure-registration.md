# 보물 등록

사용자가 승인한 현장 등록과 사전 지도 배치 두 흐름을 같은 지도·입력 화면에 구현했습니다. 기존 종이색·초록색 디자인을 유지하고, 초안은 노란 핀으로 구분합니다.

## 사용법

- **현장에서 등록:** 숨길 장소에서 `현재 위치에 등록`을 누릅니다. GPS 오차와 핀을 확인하고 힌트를 입력한 다음 `저장하고 다음`을 누릅니다. 다음 장소에서도 같은 방식으로 반복합니다. 위치는 버튼을 누를 때 받아온 좌표로 고정되며 이동 중 저절로 바뀌지 않습니다.
- **지도에서 배치:** `핀 추가` 상태에서 여러 장소를 누릅니다. 초안 목록에서 이름·힌트·종류를 입력하고, 노란 핀을 끌어 위치를 바꿉니다. `초안 N개 모두 저장`으로 함께 등록합니다. 새 핀을 놓거나 저장할 때 지도 중심과 배율을 유지합니다.
- **복제:** 초안 또는 등록된 보물의 복제 버튼을 누르면 새 ID로 이름·힌트·종류·좌표·설정을 복사합니다. 지도에서 새 위치를 지정할 수 있습니다. 발견한 보물도 복제할 수 있지만 원본 발견 기록은 변경하지 않습니다.
- **상세 설정:** 포인트(10~~1,000), 발견 반경(10~~200m), 위도·경도를 조정합니다. 꽝을 선택하면 포인트 입력이 숨겨집니다. GPS를 사용할 수 없으면 지도 또는 `좌표로 입력`으로 등록합니다.
- **초안:** 수정할 때마다 이 브라우저에 보관합니다. 계정·프로젝트·전체 초기화 세대별로 분리하며, 참가자에게는 저장 전 초안이 공개되지 않습니다. 초안의 휴지통 버튼은 확인 후 입력을 버립니다. 다른 기기와 초안은 동기화하지 않습니다.

## 저장 규칙

`saveTreasures`는 서버에서 권한과 모든 입력을 검증합니다. 전체 보물은 최대 100개이며 중복 ID를 거부합니다. 원본 수정 시 함께 보낸 스냅샷을 현재 값과 비교하여 다른 관리자의 수정·삭제를 덮어쓰지 않습니다. 발견된 보물은 수정할 수 없습니다. 성공한 저장을 응답 유실로 재시도해도 발견 기록을 초기화하지 않습니다.

한 항목이라도 충돌하면 원본 상태·참가자 뷰·비공개 종류에 일부만 반영하지 않습니다. 전체 초기화 세대가 바뀌면 이전 화면에서 진행 중이던 저장도 거부합니다. 이전 클라이언트의 단건 `saveTreasure`는 호환성을 위해 유지합니다.
