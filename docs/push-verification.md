# 앱을 보고 있을 때 푸시 알림 누락 수정

검증일: 2026-09-16.

## 원인과 수정

- 이전 서비스 워커는 Firebase의 `onBackgroundMessage`에서만 시스템 알림을 생성했습니다. 수신 기기에서 앱이 보이는 경우 SDK는 `onMessage`로만 전달했고 앱은 짧은 화면 안내만 표시했습니다.
- data-only 메시지의 시스템 알림을 서비스 워커의 `push` 이벤트에서 생성합니다. 페이지 표시 여부와 관계없이 한 번 생성하며, 표시 완료까지 이벤트 수명을 유지합니다. 기존 SDK의 앱 안 안내와 구독 갱신은 유지합니다.
- 프로필은 저장된 토큰뿐 아니라 실제 알림 권한과 브라우저 구독을 확인합니다. 등록이 끊기거나 권한이 차단된 상태를 구분하며 재연결 동작을 제공합니다. 재연결 시 새 토큰을 서버에 등록한 후 이전 토큰을 정리합니다.
- 권한 요청은 버튼을 누른 직후 수행하며, 서비스 워커 등록이 일시적으로 실패해도 다시 시도할 수 있습니다.

## 자동·브라우저 검증

- 새 푸시 테스트 14개를 포함해 단위 테스트 87개 통과. 프런트엔드·Functions 빌드 및 서비스 워커 별도 TypeScript 검사 통과.
- 기존 Firebase 에뮬레이터 테스트 25개는 이번 프런트엔드 변경에서 실행하지 않았습니다.
- 실제 Chromium 서비스 워커에 DevTools의 가상 Web Push를 전달하여 보이는 페이지·숨겨진 페이지 양쪽 모두 제목·본문·태그가 맞는 시스템 알림이 정확히 한 개 생성됨을 `getNotifications()`로 확인했습니다.
- 저장 토큰은 있지만 실제 구독이 없는 상태에서 ‘알림 연결이 끊겼어요’ 표시 확인. 390px 모바일 화면의 가로 넘침·페이지 오류 없음.
- 검증 결과와 화면은 Git에서 제외된 `artifacts/push-browser-results.json`, `artifacts/push-profile-mobile.png`에 저장했습니다.

실제 FCM 전송망과 사용자의 안드로이드 알림 표시까지 자동 검증한 것은 아닙니다. 업데이트를 적용한 휴대폰에서 앱을 보고 있을 때와 잠금 화면 상태의 최종 수신 확인이 필요합니다.
