# 참가자 명단·알림·기기 상태

## 명단 붙여넣기

대원 정보에는 영문명과 아이디를 표시하며, 한 명 추가 시 아이디와 팀만 입력합니다. 별도의 한글 이름은 입력하지 않습니다.

`추진위원회 → 참가자·권한 → 명단 붙여넣기`에서 엑셀·구글 시트의 **영문명, 팀명** 2열을 복사합니다. 40명 정도의 명단을 한 번에 등록할 수 있으며, 한 번에 100명·전체 500명까지 지원합니다.

```text
영문명      팀명
hana.kim    노랑팀
jun.lee     초록팀
minsu.park  미배정
```

탭·쉼표·공백 구분을 지원합니다. 첫 제목 행은 생략해도 됩니다. 기존 이름·영문명·팀명 3열 명단도 읽을 수 있으며 첫 번째 이름 열은 사용하지 않습니다. 영문명은 소문자로 바꾸고 기존 아이디 규칙(영문 소문자, 숫자, 점, 밑줄, 하이픈)으로 검사합니다. 팀명이 비어 있으면 ‘미배정’을 입력합니다.

등록 전 행별 미리보기에서 누락·중복·기존 참가자와의 충돌을 확인합니다. 오류가 있으면 전체를 저장하지 않습니다. 등록에 성공하면 영문명·팀명·개인 링크를 한 번에 복사하거나 TSV 파일로 저장할 수 있습니다. 개인 링크를 닫기 전에 보관하고, 각 참가자에게 본인 링크만 전달합니다.

서버는 참가자·인증 프로필·초대장·공개 상태를 같은 트랜잭션에서 저장합니다. 동일한 요청의 재시도는 같은 결과를 반환하며 중복 인원을 생성하지 않습니다. 클라이언트는 192비트 무작위 초대 코드를 만들고, 로그인 검증에는 코드 해시를 사용합니다. 요청 지문에는 원문을 넣지 않으며, 반복 복사용 링크는 아래의 서버 전용 저장소에서 관리합니다. 이미 처리한 명단의 내용이 바뀌거나 참가자가 삭제된 뒤 재시도하면 거부합니다. 새 참가자의 권한은 항상 일반 참가자입니다.

## 전체 참가링크 복사

슈퍼 어드민은 참가자 목록의 `전체 대원 참가링크 복사`를 누릅니다. `영문명`과 `참가링크` 헤더 아래 전체 계정의 영문 아이디와 링크가 탭으로 구분되어 복사됩니다. 엑셀의 첫 칸에 붙여넣으면 두 열이 됩니다. 검색 필터에 가려진 인원과 운영진·본인도 포함합니다. 영문명은 같은 이름을 구분할 수 있도록 `dave.h`처럼 등록한 전체 영문 아이디를 사용합니다.

반복 복사용 원문은 클라이언트가 직접 읽을 수 없는 `inviteLinks/{uid}`에 보관합니다. 슈퍼 어드민 전용 `getMemberInvites` API만 이 명단을 반환하며, 일반 참가자와 추진위원회 계정은 호출할 수 없습니다. 참가자 공용 상태·인증 프로필·감사 로그에는 원문을 넣지 않습니다.

과거 링크는 해시만 남아 있어 원문 복원이 불가능합니다. 첫 복사 때 복사용 링크가 없는 계정에 현재 세션 버전의 추가 링크를 발급하며, 기존 링크나 로그인은 폐기하지 않습니다. 이후 같은 링크를 재사용합니다. 만료 또는 명시적 재발급 뒤에는 현재 유효한 링크를 반환합니다. 참가자 삭제·전체 초기화 시 복사용 원문도 함께 정리합니다. 개별 재발급은 기존과 동일하게 이전 링크와 로그인을 무효화합니다.

클립보드를 사용할 수 없으면 화면에 두 열을 표시해 직접 선택·복사할 수 있습니다. 실제 참가링크는 각 참가자에게 본인의 링크만 전달합니다.

## 공지 읽음·팀순위

- 소식 화면을 열면 표시된 공지를 읽음 처리합니다. 종 아이콘과 메뉴 배지는 읽지 않은 소식만 셉니다. 새 공지에는 다시 배지가 표시됩니다.
- 읽음 목록은 같은 브라우저의 계정별로 보관하며 새로고침·다른 탭에 반영됩니다. 다른 기기의 읽음 기록과는 동기화하지 않습니다.
- ‘미배정’·‘워추위’는 팀순위에서 제외합니다. 개인 점수·개인 순위·팀별 발견 기록은 유지합니다.

## 설치·푸시 기기 상태

참가자 목록의 `앱 설치·푸시`를 누르면 기기별 설치 확인, 설치 해제 감지, 최근 접속, 알림 권한, 브라우저 푸시 연결 상태를 볼 수 있습니다. 관리 화면을 보고 있을 때 1분마다 갱신하며 직접 새로고침할 수 있습니다.

- **설치 확인**: 설치된 앱 창으로 실행했거나, 설치 완료 이벤트 또는 지원 브라우저의 설치 조회에서 확인한 기록입니다. 마지막 확인 시점의 정보이며 현재 기기 전체를 실시간 조회한 결과가 아닙니다.
- **미설치 확인**: 지원 브라우저의 현재 확인에서 앱이 설치되지 않은 것으로 나타났고, 이전 설치 이력이 없는 경우입니다.
- **삭제 추정**: 같은 브라우저에서 설치 확인 이력이 있고 이후 설치가 더 이상 감지되지 않은 경우입니다. 재설치하면 현재 상태는 설치 확인으로 돌아가며 과거 해제 감지 시각은 보존합니다.
- **설치 미확인**: 업데이트된 앱에 아직 접속하지 않았거나 설치 조회를 지원하지 않는 경우입니다. 미설치로 단정하지 않습니다.
- **푸시 등록 N대**: 서버에 남아 있는 기기 등록 수입니다. 새 등록은 브라우저 기기 ID로 중복을 제거합니다. 기기 ID가 없는 이전 등록은 토큰별로 셉니다. 권한 차단·기기 오프라인 등으로 실제 수신하지 못할 수 있으므로 상세 화면의 연결 상태도 확인합니다.

삭제 후 재접속하지 않으면 삭제 여부를 알 수 없습니다. 브라우저 데이터 삭제·다른 브라우저 사용은 기존 기록과 연결되지 않을 수 있습니다. 지원되지 않는 설치 조회나 네트워크 오류를 설치 해제로 처리하지 않습니다. 관찰 보고가 늦게 도착해 새 푸시 등록을 삭제하는 일을 막기 위해, 토큰 삭제는 명시적 알림 해제와 FCM의 무효 토큰 응답에서만 처리합니다.

기기 기록은 참가자 공용 상태에 넣지 않으며 관리자 전용 API로만 읽습니다. 참가자는 자기 계정의 상태만 보고할 수 있습니다. 원본 푸시 토큰은 관리자 화면에도 보내지 않습니다. 참가자 삭제 시 해당 기기 기록을 함께 지우고, 전체 초기화 시 슈퍼 어드민 기록만 유지합니다.

홈 화면 설치 감지는 [공식 PWA 감지 안내](https://web.dev/learn/pwa/detection), 지원 브라우저와 관련 앱 매니페스트 설정은 [Chrome 공식 문서](https://developer.chrome.com/docs/capabilities/get-installed-related-apps)를 따릅니다. 다른 도메인에 배포할 때는 빌드 환경의 `SITE_ORIGIN`을 해당 원점으로 설정합니다. 기본값은 현재 운영 도메인 `https://dave915.github.io`입니다.

## 검증

- 단위 테스트 101개: 40행 붙여넣기·입력 오류·원자적 등록·팀순위 제외·읽음 상태·설치 근거·푸시 회귀 포함.
- Firebase 통합 테스트 19개: 40명 일괄 생성, 처음·마지막 참가자 실제 코드 입장, 재시도 중복 방지, 참가자 권한 제한, 기기 조회 권한, 토큰 비노출, 삭제·초기화 정리 포함.
- Firestore 보안 규칙 테스트: 기기 기록과 일괄 요청 마커의 직접 읽기 차단.
- 브라우저: 예시 인원 6명 → 46명, 초대 링크 40개 생성, 390px 모바일 화면, 배지 해제·새로고침 유지·새 공지 배지 재표시, 팀순위 제외, 기기 상세 화면을 확인했습니다.
- 실제 40명의 운영 참가자는 생성하지 않았습니다. 기존 이용자의 설치 정보는 업데이트된 앱에 접속한 시점부터 수집됩니다.
