# 큰 방향 안내

큰 지도에서 힌트를 골라 탐색을 시작한 뒤 하단 나침반 안내를 누르면 큰 방향 화면이 열립니다.

- 화살표는 북쪽 고정이 아니라 **현재 휴대폰 방향 기준**입니다. 보물 방향과의 차이를 회전값으로 사용합니다.
- 두 방향 차이가 20° 이내면 초록색 화면과 ‘방향이 맞아요’ 표시로 안내합니다. 북쪽이나 ±180° 경계를 넘을 때 화살표가 한 바퀴 돌아가지 않도록 회전을 이어줍니다.
- 거리는 기존 서버의 GPS 기반 대략적인 거리이며, AirTag의 UWB 정밀 탐색과 같은 정확도를 제공하지 않습니다. GPS 오차를 함께 표시합니다.
- 위치가 오래됐거나 부정확하면 거리·화살표를 숨깁니다. 방향 센서가 끊기면 화살표를 숨기고 방향 켜기를 제공합니다. 위치·방향 권한 요청은 버튼 동작 안에서 수행합니다.
- 발견 반경 + 20m 이내에 들어오면 서버가 보물 방향 안내를 중단하고, 지도·큰 나침반의 방향과 거리 안내를 카메라 탐색 안내로 바꿉니다. 기본 반경 10m에서는 30m부터 카메라로 찾고, 10m 안에서 실제 카메라 화면으로 획득합니다.
- 지도 보기·뒤로 가기·Escape는 같은 지도로 돌아갑니다. 지도와 GPS 감시를 새로 만들지 않으며, 큰 지도를 닫으면 방향 센서를 정리합니다. 움직임 줄이기 설정에서는 화살표 전환 효과를 끕니다.

## 검증 (2026-09-16)

- 단위 테스트 105개와 타입 검사·프런트엔드·Functions 빌드 통과.
- Firebase 통합 20개·보안 규칙 8개 통과. 전체 링크 재사용, 기존 링크·로그인 유지, 신규·재발급 링크 반영, 삭제 후 제거, 슈퍼 어드민 권한과 직접 원문 읽기 차단 포함.
- 브라우저에서 전체 링크 두 열 복사, 검색 필터 무시, 반복 복사 시 동일 링크 확인.
- 가상 GPS·절대 방향 센서로 큰 지도 → 나침반 확대, 좌우 회전·일치 강조·센서 끊김·부정확한 위치·발견 범위 전환·지도 복귀를 검증합니다. 실제 휴대폰의 센서 정확도는 별도 현장 확인이 필요합니다.
