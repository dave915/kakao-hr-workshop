# 금액별 발견 이미지

발견 결과의 `outcome`·`prizeAmount`에 맞춰 8종의 기본 이미지를 표시합니다. 참가자가 찾기 전에는 공통 AR 보물상자를 유지하며, 해당 보물의 금액을 노출하지 않습니다.

| 금액 | 이미지 | 파일 |
| --- | --- | --- |
| 50,000원 | 왕관과 금화가 담긴 황금 보물상자 | `public/prize-art/50000-v1.webp` |
| 30,000원 | 파란 보석과 황금 받침 | `public/prize-art/30000-v1.webp` |
| 20,000원 | 초록 보석과 탐험 지도 | `public/prize-art/20000-v1.webp` |
| 10,000원 | 금화가 가득한 보물상자 | `public/prize-art/10000-v1.webp` |
| 5,000원 | 초록 끈의 금화 주머니 | `public/prize-art/5000-v1.webp` |
| 2,000원 | 별 금화 두 개 | `public/prize-art/2000-v1.webp` |
| 1,000원 | 클로버 금화 | `public/prize-art/1000-v1.webp` |
| 꽝 | 나뭇잎만 남은 빈 상자 | `public/prize-art/0-v1.webp` |

관리자는 **보물 놓기 → 발견 이미지 미리보기**에서 금액을 눌러 실제 발견 화면과 같은 구성으로 확인할 수 있습니다. 미리보기는 보물 발견·점수·재고·휴식 상태를 변경하지 않습니다.

기존 금액 미지정 보물은 공통 금화 상자와 기존 포인트 문구를 표시합니다. 이미지를 불러오지 못하면 이전 선물·꽝 아이콘으로 대체하며, 실제 금액과 결과 문구는 그대로 유지합니다.

## 이미지 제작

- 내장 `image_gen` 도구로 이미지별로 별도 생성했습니다. 따뜻한 황금색·숲 초록색·종이 질감의 탐험 일러스트이며, 50,000원 이미지를 나머지 이미지의 화풍 참고로 사용했습니다.
- 전체 생성 프롬프트: [prize-art-prompts.json](prize-art-prompts.json).
- 원본의 투명 배경을 보존해 768×768 WebP로 최적화했습니다. 8개 합계 약 0.95MB이며, 그림 속 금액 대신 앱의 실제 결과 텍스트로 금액을 표시합니다.
- Vite의 base path를 따르는 경로를 사용하며 8개 이미지는 PWA 사전 캐시에 포함됩니다.

## 검증 — 2026-10-01

- 단위 테스트 132개와 프런트엔드·서버 빌드 통과.
- 모바일 390×844와 데스크톱 1440×1000에서 8개 미리보기의 금액·이미지 연결, 이미지 디코딩, 가로 넘침 없음, 미리보기 전후 게임 데이터 무변경을 확인했습니다.
- 이미지 오류 이벤트를 모의 발생시켜 대체 아이콘과 금액 문구 유지를 확인했습니다. 브라우저 런타임 오류가 없으며, 8개 파일 모두 투명도와 768×768 크기를 확인했습니다.
- 이번 변경은 발견 화면과 이미지에 한정하며 서버의 발견 판정·점수·수량 규칙은 변경하지 않습니다.
